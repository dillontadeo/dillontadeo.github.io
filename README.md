# Dillon Tadeo — personal site

Site for hiring teams. Static HTML/CSS/JS. No build step.

## Preview

```bash
python3 -m http.server 5173
```

Open [http://localhost:5173](http://localhost:5173).

## Deploy

Drop the folder on [Netlify Drop](https://app.netlify.com/drop) or Cloudflare Pages, or use GitHub Pages from the repo root.
